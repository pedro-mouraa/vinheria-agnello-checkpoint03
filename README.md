# Vinheria Agnello

A Vinheria Agnello é uma Vinheria Muito utilizada pelas pessoas pois nela podemos adicionar Vinhos, Listar Vinhos, Mostrar vinhos com estoque baixo, calcular o estoque e exibir todos os Vinhos da Vinheria Agnello.

1 - Adicionar novos vinhos ao array
2 - Listar todos os vinhos com forEach
3 - Mostrar vinhos com estoque baixo usando filter
4 - Calcular estoque total com reduce
5 - Exibir nomes dos vinhos em caixa alta com map
